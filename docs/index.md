# Dirplay Privacy Policy

**Effective date: September 26, 2026**

Dirplay is a local music and video player. Our privacy policy is simple because there is nothing to disclose:

## Dirplay collects no data

- **No data collection.** Dirplay does not collect, store, or transmit any personal information, usage data, or analytics of any kind.
- **No tracking.** There are no analytics SDKs, no advertising identifiers, no third-party trackers.
- **No accounts.** There is nothing to sign up for.
- **No ads.** Ever.
- **Your files stay on your device.** Dirplay reads the folder you choose using Apple's standard file access APIs and plays your media. Your files, playback history, and folder structure never leave your device. There is no server and no database.

## Network access

Dirplay makes exactly one type of network request: on launch it asks Apple's public iTunes Lookup API whether a newer version of the app is available, so it can prompt you to update. This request contains no personal information — only the app's public bundle identifier — and nothing about you or your files is sent.
